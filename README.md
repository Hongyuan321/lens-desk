# 映务台 · 校园影像器材借还与缺件复核

吴宏远 ｜ 开源创新思维课程项目

相机包交回值班桌，机身和镜头都在，但少了一张 SD 卡。这套器材还能借给下一组吗？映务台把“收到器材”和“齐套可借”分别记录。值班员按清单清点，下一班能看到缺什么、谁经手、什么时候补齐。

## 运行

解压整个项目后，用 Edge 或 Chrome 打开 `index.html`。浏览器需要允许 IndexedDB 存储。若浏览器限制本地文件存储，可用 Node.js 18 或以上版本在项目目录运行以下命令。无需安装第三方包。

```sh
node serve.js
```

打开 <http://127.0.0.1:4173>。使用过程中保持相同的浏览器和地址，刷新后记录仍在。文件直开、本地服务和 GitHub Pages 各自有独立的台账。首次打开时自动生成三套示例器材。

## 三分钟课堂演示

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 选“活动摄影套装 CAM-01”，填写经办人、借用团队和应还日，保存借出登记 | 状态由可借变为借出中，交接记录出现团队与期限 |
| 2 | 归还时依次登记机身 1、镜头 1、电池 2、SD 卡 0 | 转为待复核，保留原借用团队，卡片无法再次借出 |
| 3 | 刷新页面，筛选“待复核”并选 CAM-01 | 仍可查到首次清点结果和缺卡记录 |
| 4 | 找回卡后把 SD 卡累计实收改成 1，填写经办人和复核依据，再保存 | 恢复可借，首次缺件与后续补齐的两条记录均可查看 |

另有 AUD-02 逾期借出案例和 LGT-03 缺少电源适配器案例，适合直接演示催还和换班复核。数据均为合成示例。

## 课程调研与使用范围

点名册列出了项目选题和仓库地址。选题时参考了同学如何组织业务材料与可运行原型，未使用其实现或数据。参考项目为 [退货验收与售后协同](https://github.com/zzh-127/oss-license-scan/tree/master/退货验收与售后协同) 和 [光伏发电与资产巡检](https://github.com/Emily-0717/pv-asset-inspection)。
