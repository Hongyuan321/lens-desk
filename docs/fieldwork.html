一套相机什么时候算还清？

周五 16:40，校报摄影组把相机包交回值班桌。值班员在群里回复“收到”。十分钟后，下一组准备借用，才发现收纳袋里少了一张 SD 卡。第一组认为交包就算还清，第二组却拿到一套无法立即使用的器材。

这是为课堂构造的情境。以下清单、交接单和规则均为原创模拟材料。实际发生频率、耗时和使用者意见有待实地核对。

四份可交叉核对的材料

S1 · 套装配置卡

CAM-01 活动摄影套装应包含机身 1、标准变焦镜头 1、电池 2、SD 存储卡 1。电池按两块点数，勾选“有电池”无法判断是否齐套。

S2 · 借出登记样单

11 月 26 日上午，校报摄影组借走 CAM-01，约定当天归还。样单留有套装编号、团队、经办人、出借时间和应还日期。套装配置以 S1 为准。

S3 · 归还与补件样单

时点实收（顺序同 S1）记录
16:401 / 1 / 2 / 0交回相机包，SD 卡待补
17:051 / 1 / 2 / 1从读卡器取回，同原套装核对

S4 · 值班交接规则草案

借出时登记团队和应还日。归还按配置卡逐项填写实收数量，缺件套装交给下一班复核，期间暂停出借。复核记录经办人、累计实收数量和依据。全部点齐后恢复可借。

业务机会与取舍

样单里“包已收到”和“配件已齐”相差 25 分钟。拟解决的首要问题是这段时间内套装可能再次出借。S1 给出应收，S3 给出实收，S4 决定是否放行。逾期提醒列为次要机会；损坏鉴定、赔偿和个人信用评分超出本原型范围。

现状假设　借用人交包 → 值班员回消息 → 下一组开包检查 → 发现缺件再联系上一组。待验证之处是工作人员是否已有统一的逐项登记和换班办法。

拟议流程　可借 → 登记借出 → 归还清点。齐套直接入库；缺件转待复核。复核后仍有缺口则继续挂账，累计实收与清单相等才重新开放借用。

现场调研提纲

  • 请值班员拿一张去除个人信息的最近归还单，指出哪一栏能证明存储卡已收回。观察清点一套器材所需时间。
  • 请借用人复述最近一次归还过程，说明收到哪种反馈后会认为交接结束。
  • 请换班负责人用上一班记录找一笔待补件，核对缺什么、由谁跟进、补齐后如何恢复可借。

真实访谈日期、角色、原话、单据来源及同意使用的范围均待填写。正式调研可给样本匿名编号，再将结论链接到对应单据。

试点怎么判断有用

指标计算与验证方法
缺件误放行次数逐笔核对待复核区间内是否出现新借出。原型验收目标为 0。
清点完整率填写全部组件数量的归还单 ÷ 归还单总数。空数量与实收 0 分开记录。
缺件关闭时长从首次登记缺件至齐套入库的时间。S3 的单笔示例值为 25 分钟。

拟由器材室值班员在一次活动前后试用。先采集原流程基线，再按相同套装类型比较。这里没有实际试点数据，也没有节省工时的实测结论。
